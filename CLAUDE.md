# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

Marketing website (Arabic, RTL) for "حجابات البشائر" (Al-Basha'er), a Syrian scarf/hijab manufacturer. Next.js (App Router) + TypeScript + Tailwind CSS 4. No backend, database, or tests yet.

`AGENTS.md` warns that this Next.js version (16.x) has breaking changes: read the relevant guide in `node_modules/next/dist/docs/` before writing Next-specific code.

## Commands

```bash
npm run dev            # dev server at http://localhost:3000
npm run build          # production build (also runs type checking)
npm run lint           # eslint
npx tsc --noEmit       # standalone typecheck
```

There is no test runner. Verification is `lint` + `tsc` + `build`.

- Don't run `npm run build` while `npm run dev` is running: they share `.next/` and the dev server then serves stale or broken CSS. If that happens, stop the server, delete `.next`, restart.
- `LayoutProps` (used in `app/layout.tsx`) is a global type generated by Next during `dev`/`build`; `tsc` fails on a fresh checkout until one of them has run.

## Architecture

- **Tailwind 4 is CSS-first: there is no `tailwind.config`.** Theme tokens live in `app/globals.css`: brand colors are CSS variables (`--brand-*`) under `:root`, mapped to utilities (`bg-primary`, `text-secondary`, `bg-secondary-soft`, `text-foreground`, ...) in an `@theme inline` block. Change the palette by editing the `:root` values only.
- **Tailwind is wired through Turbopack in `next.config.ts`** (`turbopack.rules` with the `@tailwindcss/turbopack` loader); there is no `postcss.config`. Edit `next.config.ts` by merging into it, never overwrite it: losing that block makes `@theme` fail to parse and the whole site renders unstyled. The same file enables `cacheComponents` and `partialPrefetching`, and allowlists `images.unsplash.com` for `next/image`.
- `.bg-pattern` in `globals.css` is an unlayered class that sets the purple gradient plus geometric pattern as `background-image`. Because it is unlayered it overrides Tailwind `bg-*`/gradient utilities on the same element; don't combine them.
- **RTL/Arabic:** `app/layout.tsx` sets `lang="ar" dir="rtl"`, loads Tajawal via `next/font` into `--font-tajawal`, and renders `Header` / `{children}` / `Footer` for every page. Phone numbers and emails must use `dir="ltr"` to display correctly.
- **Single source of content:** `lib/site.ts` holds the company name, slogan, address, phones (`phones[]`, the `whatsapp: true` entry links to `wa.me`) and `navLinks` used by Header, Footer and the contact page. `data/products.ts` holds the `Product` interface and the six products (`isFeatured` decides which appear in `components/home/LatestProducts.tsx`); `ProductGrid`/`ProductCard` render them on `/products`. Shared non-product types are in `types/index.ts`; `heroImage` lives in `lib/site.ts`. Update content there, not in components. `README.md` documents the add-product / replace-image / replace-logo workflow for the site owner; keep it in sync.
- Product images are local files in `public/images/products/`; `components/ProductImage.tsx` (client) falls back to `placeholderImage` (Unsplash) via `onError` when a file is missing. The logo is `public/images/logo.png` (a generated placeholder meant to be overwritten with the real file; sizing is set in `components/Logo.tsx`).
- Components: `components/` holds shared pieces (Header is a client component for the mobile menu and active link; `icons.tsx` is a small inline-SVG set, no icon library), `components/home/` holds home-page sections. The home page (`app/page.tsx`) only composes them.

## Animations

No animation library. Keyframes and helper classes (`animate-fade-up`, `animate-float`, `animate-marquee`, `text-shimmer`, `btn-shine`, `.reveal`) are plain CSS at the bottom of `app/globals.css`, with a `prefers-reduced-motion` override. Scroll-in effects go through `components/Reveal.tsx` (IntersectionObserver client wrapper; `delay` staggers grids). Wrap new sections in `Reveal` or use `SectionHeading`, which already does.

## Conventions

- `siteConfig.instagramUrl` in `lib/site.ts` is intentionally empty; when set, the contact page and footer show an Instagram entry automatically.
- The logo `Image` is `unoptimized`, so overwriting `public/images/logo.png` takes effect immediately (the image optimizer cache otherwise serves the old file).

- All user-facing copy is Arabic (formal, feminine address to the customer, e.g. "تسوقي الآن"). The contact page uses the label "اتصل بنا" and has no form by design.
- Avoid adding UI libraries; icons and buttons are hand-rolled (`components/Button.tsx` is a `next/link`-based button).
- Source files contain Arabic UTF-8. On Windows, don't rewrite them with PowerShell 5.1 `Get-Content`/`Set-Content` pipelines (it double-encodes them into mojibake); use the Edit/Write tools.
