# موقع حجابات البشائر

موقع تعريفي (Next.js + Tailwind CSS) لشركة حجابات البشائر في دمشق - الحريقة، سوريا.

## تشغيل الموقع

```bash
npm install     # مرة واحدة فقط
npm run dev     # ثم افتح http://localhost:3000
```

للتحقق من سلامة الكود قبل النشر:

```bash
npm run lint
npx tsc --noEmit
npm run build
```

> لا تشغّل `npm run build` أثناء تشغيل `npm run dev` (يتشاركان مجلد `.next`).

---

## 1. إضافة منتج جديد

كل المنتجات في ملف واحد: **`data/products.ts`**. لا تحتاج لتعديل أي ملف تصميم.

1. ضع صورة المنتج في `public/images/products/` (مثلاً `cotton-scarf.jpg`).
2. افتح `data/products.ts` وأضف عنصراً جديداً في نهاية المصفوفة `products`:

```ts
{
  id: 7,                                   // رقم فريد (لا يتكرر)
  name: "حجاب شيفون",
  description: "وصف قصير للمنتج.",
  image: "/images/products/cotton-scarf.jpg",
  colors: ALL_COLORS,                      // أو ["أسود", "وردي", "بيج"]
  isFeatured: false,                       // true ليظهر في الصفحة الرئيسية
},
```

3. احفظ الملف، فيظهر المنتج تلقائياً في صفحة المنتجات.

- **`colors`:** `ALL_COLORS` تعرض شارة "متوفر بجميع الألوان"، ومصفوفة أسماء تعرض كل لون كوسم منفصل.
- **`isFeatured`:** المنتجات التي قيمتها `true` تظهر في قسم "أحدث المنتجات" بالصفحة الرئيسية. يُفضّل أن تكون 3 منتجات.
- **حذف منتج:** احذف العنصر من المصفوفة.

## 2. استبدال صورة منتج

1. أنشئ صورتك الجديدة، ويفضّل أن تكون **عمودية بنسبة 4:5** (مثلاً 800×1000 بكسل) وحجمها أقل من 300 كيلوبايت.
2. ضعها في `public/images/products/` **بنفس اسم الصورة القديمة** (وبنفس الامتداد) لتحلّ مكانها.
   - مثال: لاستبدال صورة "حجاب ليكرا قطعتين" ضع ملفاً باسم `lecra-2-pieces.jpg`.
   - أو ضعها باسم جديد وغيّر قيمة `image` في `data/products.ts`.
3. إذا لم تُوجد الصورة تظهر صورة افتراضية تلقائياً بدل صورة مكسورة.

بعد الاستبدال قد تحتاج تحديث الصفحة بقوة (Ctrl+F5) لرؤية الصورة الجديدة.

## 3. استبدال الشعار

ضع ملف الشعار باسم **`logo.png`** في `public/images/` ليحلّ مكان القديم. يظهر الشعار في الهيدر والفوتر.

- يفضّل PNG بخلفية شفافة، والأبعاد الحالية 520×160 بكسل.
- إذا اختلفت نسبة صورتك عن ذلك، عدّل `width` و`height` في `components/Logo.tsx`.
