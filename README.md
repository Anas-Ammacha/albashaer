# موقع حجابات البشائر

موقع تعريفي (Next.js + Tailwind CSS) لشركة حجابات البشائر في دمشق - الحريقة، سوريا.
صفحاته: الرئيسية، من نحن، اتصل بنا.

## تشغيل الموقع

```bash
npm install     # مرة واحدة فقط
npm run dev     # ثم افتح http://localhost:3000
```

للتحقق من سلامة الكود قبل النشر:

```bash
npm run lint
npx tsc --noEmit
npm run build
```

> لا تشغّل `npm run build` أثناء تشغيل `npm run dev` (يتشاركان مجلد `.next`).

---

## 1. استبدال الشعار

ضع ملف الشعار باسم **`logo.png`** في `public/images/` ليحلّ مكان القديم. يظهر الشعار في الهيدر والفوتر.

- يفضّل PNG بخلفية شفافة، والأبعاد الحالية 520×160 بكسل.
- إذا اختلفت نسبة صورتك عن ذلك، عدّل `width` و`height` في `components/Logo.tsx`.

## 2. استبدال صورتي الحجاب في أعلى الصفحة الرئيسية

الصورتان داخل الإطارين المقوّسين موجودتان في `public/images/lifestyle/`:

- `hijab-gold.jpg`: الصورة الكبيرة.
- `hijab-calm.jpg`: الصورة الصغيرة.

استبدليهما بنفس الاسم وبنفس الامتداد. يفضّل أن تكونا **عموديتين بنسبة 4:5** (مثلاً 900×1125 بكسل)، وأن يكون الوجه في النصف العلوي من الصورة، وبخلفية فاتحة بسيطة.

**إذا لم تتغير الصورة بعد الاستبدال:** اضغطي Ctrl+F5. وإن بقيت القديمة، أوقفي `npm run dev` واحذفي مجلد `.next/cache/images` ثم شغّليه من جديد.

## 3. تعديل المعلومات الأساسية

كل المعلومات في ملف واحد: **`lib/site.ts`**.

| ما تريدين تغييره | المكان في `lib/site.ts` |
| --- | --- |
| الاسم، الشعار النصي، العنوان | `siteConfig` |
| ساعات العمل (تظهر في الفوتر واتصل بنا) | `siteConfig.workingHours` |
| رابط واتساب، رابط إنستغرام | `siteConfig.whatsappUrl` و`siteConfig.instagramUrl` |
| أرقام الهاتف | `phones` |
| روابط القائمة | `navLinks` |

## 4. تعديلات أخرى

| ما تريدين تغييره | الملف |
| --- | --- |
| ألوان الموقع | `app/globals.css` (المتغيرات `--brand-*` في أعلى الملف) |
| صورة صفحة "من نحن" | `public/images/about.jpg` |
| نصوص "من نحن" (القصة، الرؤية، الرسالة، القيم) | `app/about/page.tsx` |
| نص البيع بالجملة والشحن | `app/contact/page.tsx` |
| نقاط الثقة تحت الهيرو | `components/home/TrustStrip.tsx` |
